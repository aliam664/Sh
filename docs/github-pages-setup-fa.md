# 🌐 راهنمای سایت‌کردن بازی با GitHub Pages (یک‌بار، ۱ دقیقه)

بازی «دوئل رمز» دقیقاً **در ریشهٔ همین ریپو** قرار دارد — `index.html` + `style.css` + `game.js`، بدون هیچ پوشه‌ای. GitHub Pages می‌تواند آن را به یک **سایت زنده** تبدیل کند؛ فقط فعال‌سازی نیاز به یک کلیک شما دارد (دسترسی توکن ربات به تنظیمات Pages محدود است).

---

## ✅ فعال‌سازی (فقط یک‌بار)

**با گوشی** یا کامپیوتر:

1. این لینک را باز کنید: <https://github.com/aliam664/Sh/settings/pages>
   - روی گوشی: در Chrome از منوی ⋮ گزینهٔ **Desktop site** را روشن کنید.
2. بخش **Build and deployment** → زیر **Branch**:
   - برنچ: **`arena/019fb378-sh`** را انتخاب کنید
   - پوشه: **`/ (root)`** را انتخاب کنید ← چون بازی در ریشهٔ ریپوست
3. **Save** را بزنید و ~۱ دقیقه صبر کنید. ✅

> بعداً هر وقت این برنچ را روی `main` مرج کردید، می‌توانید در همین صفحه برنچ را به `main` تغییر دهید.
