# راهنمای قدم‌به‌قدم اجرای «رمزو» — از صفر تا بازی 🎮

این راهنما برای کسی نوشته شده که می‌خواهد پروژه را بسازد و بازی کند — بدون هیچ پیش‌زمینه‌ای فرض نکنید، همه‌چیز قدم‌به‌قدم آمده.

> 📱 **PC ندارید؟** هیچ مشکلی نیست! راهنمای کامل «ساخت و نصب فقط با گوشی» را ببینید:
> **[docs/build-without-pc-fa.md](build-without-pc-fa.md)** — با مرورگر گوشی APK آماده از گیت‌هاب بگیرید (۵ قدم، ۱۰ دقیقه) یا با Termux روی خود گوشی بسازید.

---

## 🧰 آنچه لازم دارید (چک‌لیست)

| چیز | کجا/چرا |
|---|---|
| یک کامپیوتر (ویندوز/مک/لینوکس) | برای ساختن اپلیکیشن — فقط یک‌بار |
| اینترنت روی کامپیوتر | فقط برای دانلود ابزارها و وابستگی‌ها (بار اول) |
| **گوشی اندروید (نسخهٔ ۸ / API 26 به بالا)** | گوشیِ **میزبان** — فقط همین یک گوشی اپ می‌خواهد |
| گوشی‌های دیگر بازیکن‌ها | **هیچ چیزی لازم ندارند** (مرورگر کافی است — حتی آیفون) |

## مرحلهٔ ۱️⃣: دریافت کد روی کامپیوتر

یکی از دو روش:

**روش الف — دانلود ZIP (ساده‌تر):**
1. این لینک را در مرورگر باز کنید: `https://github.com/aliam664/Sh/archive/refs/heads/arena/019fb378-sh.zip`
2. فایل ZIP را استخراج (Extract) کنید، مثلاً در `C:\Projects\Sh` یا `~/Sh`.

**روش ب — با Git:**
```bash
git clone -b arena/019fb378-sh https://github.com/aliam664/Sh.git
cd Sh
```

---

## مرحلهٔ ۲️⃣: نصب Android Studio

1. از `developer.android.com/studio` آخرین نسخه را دانلود و نصب کنید.
2. در اولین اجرا، حالت **Standard** را انتخاب کنید تا SDK اندروید هم نصب شود (JDK 17 داخل خود برنامه هست).

---

## مرحلهٔ ۳️⃣: بازکردن پروژه و نهیدن (Sync)

1. Android Studio را باز کنید → **Open** → پوشهٔ پروژه (همان جایی که `settings.gradle.kts` هست) را انتخاب کنید.
2. صبر کنید **Gradle Sync** تمام شود (نوار پایین صفحه). بار اول چند دقیقه طول می‌کشد چون وابستگی‌ها دانلود می‌شوند.
   - اگر دربارهٔ `gradle-wrapper` پیغام داد، گزینهٔ **Use Gradle wrapper** را بزنید.
   - اگر `gradle-wrapper.jar` را گم‌شده اعلام کرد، Studio خودش بازتولیدش می‌کند؛ اگر نکرد، ترمینال پایین صفحه را باز کنید و بزنید: `gradle wrapper --gradle-version 8.7` (نیازمند نصب Gradle سیستم).

✅ وقتی سینک بدون خطا تمام شد، آماده‌اید.

---

## مرحلهٔ ۴️⃣: ساختن و نصب اپ روی گوشی میزبان

### روش الف — با کابل USB (توصیه‌شده)
1. روی گوشی: **تنظیمات ▸ دربارهٔ تلفن** → ۷ بار روی **Build number** بزنید تا حالت توسعه‌دهنده باز شود.
2. **تنظیمات ▸ Developer options** → **USB debugging** را روشن کنید.
3. گوشی را با کابل به کامپیوتر وصل کنید؛ روی گوشی پیام «اجازهٔ دیباگ USB» می‌آید → **Allow**.
4. در Android Studio بالای صفحه گوشی را انتخاب کنید و دکمهٔ **Run ▶** را بزنید — اپ ساخته و خودکار روی گوشی نصب و باز می‌شود.

### روش ب — ساخت فایل APK و انتقال دستی
1. در Android Studio: **Build ▸ Build App Bundle(s)/APK(s) ▸ Build APK(s)**
2. فایل آماده می‌شود در: `app/build/outputs/apk/debug/app-debug.apk`
3. APK را به گوشی منتقل کنید (کابل/تلگرام/ShareIt) و روی گوشی نصب کنید.
   - اندروید پیام «نصب از منابع ناشناس» می‌دهد → برای آن فایل‌منیجر/مرورگر اجازه بدهید.

🔑 نکته: فقط **گوشی میزبان** به این APK نیاز دارد.

## مرحلهٔ ۵️⃣: شروع بازی 🎉

1. **میزبان** روی گوشی‌اش **هات‌اسپات** را روشن می‌کند (Mobile data می‌تواند خاموش باشد — اینترنت لازم نیست).
2. مهمان‌ها به آن هات‌اسپات وصل می‌شوند.
3. میزبان اپ رمزو را باز می‌کند → نامش را می‌نویسد → **«میزبانی بازی 👑»**.
4. روی صفحهٔ میزبان یک **QR بزرگ** + آدرس مثل `http://192.168.43.1:8080` می‌آید.
5. **مهمان‌ها:** دوربین گوشی‌شان را روی QR می‌گیرند (یا آدرس را در مرورگر تایپ می‌کنند) → صفحهٔ رمزو در مرورگر باز می‌شود → نام‌شان را می‌نویسند → وارد لابی.
6. میزبان «شروع بازی» را می‌زند → بازی شروع می‌شود:
   - صاحب رمز هر دور، کد ۴ رقمی مخفی را وارد می‌کند (از اپ اگر میزبان است، از مرورگر اگر مهمان است)
   - بقیه با کمک رنگ‌های 🟩🟨🟥 مسابقه می‌دهند — نفرتی حداکثر ۱۲ حدس
   - بعد از چرخش کامل صاحب‌رمزی بین همه، قهرمان 🏆 اعلام می‌شود

## 🩹 عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| سینک Gradle خطا داد | اینترنت کامپیوتر را چک کنید؛ File ▸ Invalidate Caches ▸ Restart |
| گوشی در لیست دستگاه‌ها نمی‌آید | درایور USB (ویندوز: ADB Driver) و روشن‌بودن USB debugging؛ کابل دیتا استفاده کنید (نه فقط شارژری) |
| QR باز شد ولی صفحه لود نشد | مطمئن شوید مهمان به **همان هات‌اسپاتِ میزبان** وصل است (نه دیتای خودش!) |
| آدرس http پیدا نشد | دقیقاً همان چیزی را بزنید که زیر QR روی صفحهٔ میزبان بزرگ نوشته شده + پورت ۸۰۸۰ |
| بعضی گوشی‌ها هات‌اسپات نمی‌دهند | به‌جای هات‌اسپات، همه را به یک **مودم/روتر** مشترک وصل کنید — همان کار می‌کند |
| بازیکن وسط بازی قطع شد | دور قفل نمی‌شود ولی بازیکن رفته تا اتاق بعدی برنمی‌گردد (محدودیت فعلی) |

## 💡 نکته‌های مفید

- تعداد بازیکن: **۲ تا ۵ نفر** (میزبان + حداکثر ۴ مهمان).
- برای تست سریع بدون مهمان واقعی: یک تب دیگر در مرورگرِ **کامپیوترِ همان شبکه** باز کنید و آدرس را بزنید — می‌توانید خودتان مهمان هم باشید! (کامپیوتر باید به همان هات‌اسپات وصل باشد)
- قواعد (طول رمز، سقف حدس، ظرفیت) در `app/src/main/java/com/ramzo/game/game/Rules.kt` قابل تغییر است.
- لاج بازی و صفحات: `docs/gdd-fa.md` و `docs/architecture-fa.md`.
