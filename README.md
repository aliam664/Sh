# رمزو 🔐 — بازی حدسِ رمز روی هات‌اسپات

**رمزو (Ramzo)** یک بازی اجتماعی اندرویدی است: یک نفر صاحبِ یک کد ۴ رقمی مخفی می‌شود و بقیه با راهنمای رنگ‌ها (🟩 درست سرِ جایش / 🟨 هست ولی جای دیگر / 🟥 اصلاً نیست) مسابقه می‌دهند — **کاملاً آفلاین، روی هات‌اسپات گوشی، بدون هیچ سرور یا اینترنتی.**

- 👥 ۲ تا ۵ بازیکن — 📶 فقط اندروید — 🏆 صاحب‌رمزی دورهای بازی می‌چرخد و در پایان قهرمان اعلام می‌شود
- اسناد طراحی: [GDD](docs/gdd-fa.md) · [معماری و پروتکل شبکه](docs/architecture-fa.md) · [امکان‌سنجی اولیه](docs/local-multiplayer-analysis-fa.md)

## 🚀 اجرای سریع (Developer Quickstart)

### پیش‌نیاز
1. **Android Studio** (نسخهٔ جدید — Koala/Ladybug یا بالاتر)
2. JDK 17 (همراه Android Studio نصب است) و Android SDK 34

### ساخت
```bash
# روش ۱ — از داخل Android Studio (توصیه‌شده):
#    File ▸ Open ▸ ریشهٔ همین مخزن ▸ صبر کنید Gradle Sync تمام شود ▸ Run ▶

# روش ۲ — خط فرمان (خروجی APK نوع debug):
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
# نصب روی گوشیِ وصل‌شده با USB:
./gradlew installDebug

# اجرای تست‌های منطق بازی (بدون نیاز به گوشی):
./gradlew test
```

> ℹ️ فایل `gradle-wrapper.jar` در این مخزن نیست؛ Android Studio در اولین Sync آن را خودکار تهیه می‌کند (یا `gradle wrapper` اگر Gradle سیستمی دارید). پروژه: Kotlin 2.0 + Jetpack Compose (Material 3)، minSdk 26، target 34.

## 🎮 روش بازی (راهنمای بازیکنان)

1. **یک نفر** هات‌اسپات گوشی‌اش را روشن می‌کند (دیتا لازم نیست!) → بقیه به آن وصل می‌شوند.
2. همه رمزو را باز می‌کنند و **نام‌شان** را می‌نویسند.
3. صاحب هات‌اسپات «**میزبانی بازی 👑**» را می‌زند؛ نام اتاق و IP روی صفحه‌اش می‌آید.
4. بقیه «**پیوستن**» — اتاق معمولاً **خودکار** در لیست ظاهر می‌شود؛ اگر نشد، IP را دستی وارد کنید.
5. میزبان «شروع بازی» می‌زند. هر دور یک نفر **صاحب رمز** است؛ کد ۴ رقمی‌اش را وارد می‌کند و بقیه **همزمان** حدس می‌زنند (نفرتی حداکثر ۱۲ حدس).
6. **اولین نفری** که رمز را حل کند امتیاز می‌گیرد؛ اگر کسی حل نکرد امتیاز به صاحب رمز می‌رسد. بعد از چرخش کامل، **قهرمان** 🏆 اعلام می‌شود.

**نکته‌های اتصال:**
- کشف خودکار روی بعضی گوشی‌ها/هات‌اسپات‌ها ممکن است محدود شود → همیشه «ورود IP دستی» کار می‌کند (IP درشت روی صفحهٔ میزبان است).
- ورود بازیکن وسط یک بازیِ در حال اجرا پشتیبانی نمی‌شود (از اتاق بعدی وارد شوید).
- همگی باید یک نسخهٔ بازی داشته باشند.

## 🏗️ ساختار پروژه

```
app/src/main/java/com/ramzo/game/
├── MainActivity.kt            ورودی اپ
├── GameViewModel.kt           هماهنگ‌کنندهٔ وضعیت UI + منطق میزبان/کلاینت (رشتهٔ منطقی تکی)
├── game/                      قواعد (Rules) + داور رنگ‌بندی (Evaluator) — خالص و تست‌پذیر
├── net/                       پروتکل NDJSON روی TCP + کشف اتاق با UDP Broadcast
└── ui/                        تم، کامپوننت‌ها و ۸ صفحهٔ Compose (RTL فارسی)
docs/                          GDD، معماری، امکان‌سنجی
```

- شبکه: هر کلاینت یک سوکت TCP به گوشی میزبان — پیام‌ها JSON خط‌به‌خط، میزبان منبع واحد حقیقت.
- پورت‌ها: TCP `48000`، کشف UDP `47777`.
- قواعد قابل‌تنظیم (طول رمز، سقف حدس، ظرفیت…) در `game/Rules.kt`.
