# رمزو 🔐 — بازی حدسِ رمز روی هات‌اسپات (مهمان‌ها بدون نصب!)

**رمزو (Ramzo)** یک بازی اجتماعی است: یک نفر صاحبِ کد ۴ رقمی مخفی می‌شود و بقیه با راهنمای رنگ‌ها (🟩 درست سرِ جایش / 🟨 هست ولی جایش نه / 🟥 اصلاً نیست) مسابقه می‌دهند — **کاملاً آفلاین روی هات‌اسپات، بدون اینترنت، بدون هیچ سروری.**

- 👑 **فقط میزبان** اپ نصب می‌کند (اندروید)
- 🌐 **مهمان‌ها هیچ چیزی نصب نمی‌کنند** — به هات‌اسپات وصل می‌شوند، QR را اسکن می‌کنند و **داخل مرورگر** بازی می‌کنند (حتی آیفون/سافاری!)
- 👥 ۲ تا ۵ بازیکن — 🏆 صاحب‌رمزی بین همه می‌چرخد و در پایان قهرمان اعلام می‌شود
- ⚔️ می‌خواهید **همین الآن** بدون هیچ نصبی دونفره بازی کنید؟ فایل مستقل **[standalone/guess-duel.html](standalone/guess-duel.html)** را روی هر گوشی با مرورگر باز کنید (دوئل نوبتی در یک گوشی — آفلاین، بدون سرور)
- اسناد: [GDD](docs/gdd-fa.md) · [معماری v2](docs/architecture-fa.md) · [امکان‌سنجی](docs/local-multiplayer-analysis-fa.md)

## 🚀 اجرای سریع (فقط برای میزبان/توسعه‌دهنده)

> 📱 **بدون PC می‌خواهید؟** → **[docs/build-without-pc-fa.md](docs/build-without-pc-fa.md)** — با مرورگر گوشی از گیت‌هاب APK آماده بگیرید یا با Termux روی خود گوشی بسازید (فایل CI آماده در `ci/android-build.yml`).

### پیش‌نیاز
1. **Android Studio** (نسخهٔ جدید)
2. JDK 17 + Android SDK 34

### ساخت
```bash
# روش ۱ — Android Studio: File ▸ Open ▸ ریشهٔ مخزن ▸ Sync ▸ Run ▶

# روش ۲ — خط فرمان:
./gradlew assembleDebug          # خروجی: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug           # نصب روی گوشیِ وصل‌شده
./gradlew test                   # تست واحد داور بازی (بدون گوشی)
```

> ℹ️ `gradle-wrapper.jar` را Android Studio در اولین Sync خودکار تهیه می‌کند. پروژه: Kotlin 2.0 + Compose + NanoHTTPD (وب‌سرور مهمان‌ها) + ZXing (QR) — minSdk 26 / target 34.

## 🎮 روش بازی (راهنمای گروه)

1. **میزبان:** هات‌اسپات گوشی‌ات را روشن کن (دیتا لازم نیست) → اپ رمزو → نام‌ات را بنویس → «میزبانی بازی 👑».
2. **مهمان‌ها:** به هات‌اسپات وصل شوید → **دوربین گوشی** را روی QR صفحهٔ میزبان بگیرید (یا آدرس `http://...:8080` را در مرورگر باز کنید) → نام‌تان را بنویسید → وارد لابی شوید.
3. میزبان «شروع بازی» می‌زند — حالا مهمان‌ها همه‌چیز را **در مرورگرشان** می‌بینند: حدس‌زدن، رنگ‌ها، صاحب‌رمزی، امتیاز و قهرمان پایانی. چیزی نصب نکردند! 🎉

**نکته‌ها:**
- ورود وسط بازی در جریان پذیرفته نمی‌شود (از اتاق بعدی).
- مهمان قطع‌شده وسط دور، دور را قفل نمی‌کند (حدس‌هایش مصرف‌شده حساب می‌شود).
- آدرس دقیق زیر QR نوشته شده — اگر اسکن نشد، دستی تایپ کنید.

## 🏗️ معماری در یک نگاه

```
گوشی میزبان (اپ)                       گوشی مهمان ۱..۴ (مرورگر)
┌───────────────────────────┐         ┌──────────────────────┐
│ GameCore (منبع حقیقت)      │◀── WS ─│ وب‌کلاینت تک‌فایلی     │
│ WebGameServer (HTTP+WS‏)   │  HTTP  │ (از / سرو می‌شود)     │
│ Compose UI (بازیِ میزبان)  │        │ کی‌پد، رنگ‌ها، امتیاز │
└───────────────────────────┘         └──────────────────────┘
        ▲ همه روی هات‌اسپات، بدون اینترنت ▲
```

- هر تغییر در `GameCore` → اسنپ‌شات شخصی JSON برای هر بازیکن (اپ میزبان + هر مرورگر).
- رمز هرگز به کلاینت‌ها نمی‌رود (جز به صاحب خودش و در افشای پایان دور).

## 📂 ساختار

```
app/src/main/java/com/ramzo/game/
├── game/   Rules + Evaluator (تست‌دار) + GameCore ⭐ (داوری/دور/امتیاز)
├── net/    NetUtils + web/WebGameServer.kt ⭐ (NanoHTTPD: / و /ws + اسنپ‌شات)
├── ui/     تم + صفحه‌های اپ میزبان (خانه، لابی با QR، بازی، نتیجه، فینال)
app/src/main/assets/web/index.html  ⭐ وب‌کلاینت مهمان‌ها (آفلاین، RTL فارسی)
docs/       GDD، معماری، امکان‌سنجی
```
